HƯỚNG DẪN CÀI ĐẶT
--------------------------------------------------
1. Giải nén file bạn vừa tải về. Bạn sẽ thấy thư mục tên là "Augusta".
2. Mở thư mục cài đặt gốc của game Grounded 2 trên máy tính của bạn.
   (Nếu chơi trên Steam: Chuột phải vào game Grounded 2 -> Manage -> Browse local files)
3. Chép (Copy) thư mục "Augusta" vừa giải nén và Dán (Paste) đè vào thư mục cài đặt gốc của game.
   (Nếu máy tính hỏi "Replace the files in the destination", hãy chọn Yes / Replace toàn bộ).
4. Mở game và tận hưởng 100% Tiếng Việt!

--------------------------------------------------
GỠ CÀI ĐẶT (UNINSTALL)
--------------------------------------------------

- Chạy  file "Uninstall_VietHoa.bat" để công cụ tự động xóa sạch các file Mod.
